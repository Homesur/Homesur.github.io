⚽ Калькулятор N исходов

📊 Распределяет ваш фиксированный бюджет так, чтобы любой выигрыш перекрывал все проигранные ставки.
📌 Исход 📈 Коэффициент
📦 Общая ставка: 0 лей
📈 Прибыль при любом исходе: 0 лей
⚠️ Все коэффициенты меньше количества исходов — прибыли не будет ни при одном исходе.
Сумма на исход = Бюджет × (1/коэф) / Σ(1/коэф)
